# Design Patterns

Este repositório foi criado pensado para ser um catálogo de estudo pessoal de padrões de projeto. Nada mais, nada menos.

Feito em TypeScript, é necessário ter node e pnpm instalado para executar os exemplos (caso queira, se quiser apenas visualizar, não é necessário).

## Como executar

Baixe as dependências:

```bash
pnpm i
```

Execute:

```bash
pnpm exec tsx cases/[design-pattern]/[problem/solution]
```

Exemplo: caso queira executar o problema do padrão `Simple Factory`:

```bash
pnpm exec tsx cases/simple-factory/problem
```
